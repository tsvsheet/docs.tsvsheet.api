# docs.tsvsheet.api

Public documentation for [`tsvsheet/tsvsheet.api`](https://github.com/tsvsheet/tsvsheet.api) — the sheet API server (`tsvsheet-api`): edit, watch, and read computed values from `.tsvt` spreadsheets over HTTP.
